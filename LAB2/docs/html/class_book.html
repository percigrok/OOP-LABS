Подробное описание

Класс для представления книги в библиотеке

Моделирует книгу с информацией о названии, авторе, количестве страниц и статусе выдачи. Обеспечивает операции выдачи и возврата книги с проверкой корректности состояния.

Инварианты класса:

  1. Количество страниц должно быть положительным (pageCount > 0)
  2. Уже выданную книгу нельзя выдать повторно
  3. Книгу, которая не была выдана, нельзя вернуть
